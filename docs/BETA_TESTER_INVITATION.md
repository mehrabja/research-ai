# Research AI — beta tester invitation draft

**Status: Draft only. No invitations have been sent.**

Use this message only after the repository and demo have been intentionally made public, the release checklist has passed, and a safe test environment is available.

---

## Invitation

I'm preparing an early public beta of Research AI, an evidence-grounded research workspace for literature discovery, source management, evidence retrieval, research planning, and manuscript workflows.

I'm looking for a small group of researchers and developers willing to test the workflow and report reproducible issues. The goal of this beta is to validate setup, usability, documentation, extraction and retrieval behavior, and the quality of the maintainer feedback loop.

What I am asking from testers:

- Try the documented local setup or the published demo, if available.
- Report the feature or workflow tested and the exact steps taken.
- Share sanitized logs and screenshots where helpful.
- Flag confusing behavior, incorrect documentation, missing tests, or broken workflows.
- Open focused issues using the repository templates.

Please do not upload confidential, unpublished, personal, regulated, or otherwise sensitive research material to a test deployment. Do not include API keys, passwords, private URLs, or private documents in issues. AI-generated summaries, evidence links, and citations must be checked against their original sources.

Project repository: https://github.com/mehrabja/research-ai

Thank you for helping test an early-stage research tool.

---

## Test feedback to collect

1. Operating system, Python version, Node version, and database setup.
2. Exact setup or workflow steps.
3. Expected result and actual result.
4. Whether the issue reproduces on a clean install.
5. Sanitized logs, screenshots, or test data that may be shared publicly.
6. Whether the result concerns correctness, security, accessibility, usability, or documentation.

The maintainer should not collect private documents or credentials as part of this tester program.
